# Dirección visual

Panel de instrumentación para un prototipo con LM35, MQ-7 y dos bombas.
Fondo azul gris #edf2f7, papel #ffffff, texto #183047, azul #175cd3,
ámbar #a65a00 y rojo #b42318. Tipografía Segoe UI con cifras tabulares.
Cabecera compacta, banda de estado prominente y dos lecturas de sensores;
debajo, gráfica de un sensor a la vez y registro de episodios. Alineación
izquierda, sin imágenes decorativas. La banda distingue datos de ejemplo,
datos recientes y datos antiguos; nunca interpreta ausencia de datos como normal.
La gráfica y el registro ocupan más espacio que los indicadores secundarios.
En móvil todo se apila sin perder controles, unidades ni fecha.
